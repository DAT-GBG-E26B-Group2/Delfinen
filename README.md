
# Delfinen – Svømmeklub

Et Java-projekt udviklet som en del af første semester på datamatikeruddannelsen.

## Projektbeskrivelse

Delfinen er et konsolbaseret administrationssystem til en svømmeklub.

Systemet skal understøtte tre brugerroller:

- **Formand:** Oprettelse og administration af medlemmer.
- **Kasserer:** Beregning af kontingent, registrering af betalinger og oversigt over restancer.
- **Træner:** Administration af konkurrencesvømmere, træningstider og stævneresultater.

Projektet udvikles med fokus på objektorienteret programmering, samarbejde, Scrum og Git.

## Funktionalitet

Projektet skal opfylde 14 obligatoriske krav (F1–F14), herunder:

- Medlemsregistrering og unikke medlemsnumre
- Medlemsoversigt
- Kontingentberegning og betalinger
- Restanceliste
- Junior- og seniorhold
- Svømmediscipliner
- Træningstider og personlige rekorder
- Stævneresultater
- Top 5-lister
- Lagring af data i tekstfiler

**Status:** Projektet er under udvikling. Punkterne ovenfor beskriver planlagt funktionalitet.

## Installation og kørsel

1. Clone repository fra GitHub.
2. Åbn projektet i IntelliJ IDEA.
3. Sørg for, at den korrekte JDK er installeret.
4. Lad IntelliJ indlæse Maven-projektet.
5. Kør programmets `Main`-klasse.

Kørselsvejledningen opdateres, efterhånden som projektet udvikles.
